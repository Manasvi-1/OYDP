01. DFD level 0 — external context
Users and invited professionals act on their own data and consent; official systems remain independent authorities, never
assumed API partners. Institutional reads are scoped to contracts and revocable grants. The platform stores private evidence and
audit event trails with document-level lineage.

Figure: DFD_LEVEL_0. Editable source: 13_DIAGRAMS/DFD_LEVEL_0.mmd

02. DFD level 1 — engine groups
Shared property identity routes referenced data to diligence, ownership, education, GIS, valuation, concepts, marketplace and
partner API. No transfer of restricted document bytes through public listing APIs. The trust boundary is checked at every
inter-engine invocation, not only the UI.
